# GeoNames catalog test fixture

These rows are a deliberately small excerpt shaped like the GeoNames
`countryInfo.txt`, `admin1CodesASCII.txt`, and `cities500.txt` downloads. The
companion `spots.json` contains verified GeoNames projections for Yellowstone
National Park and the Eiffel Tower. Together they cover Uvita, Costa Rica, two
cities named Paris, a national park, and a cultural landmark so importer and
search ranking can be tested without checking a worldwide data dump into Git.

The data is derived from GeoNames and is available under CC BY 4.0. Attribution:
https://www.geonames.org/
